# Universe Unity Starter Scaffold

This folder is a **Unity-ready scaffold** for the Universe prototype. It contains system scripts and setup instructions so you can open Unity and wire the scene quickly.

## Quick start
1. Install Unity LTS (2022.3+ recommended) with iOS Build Support and WebGL Build Support.
2. Create/open a Unity 3D project using this `engine/unity` folder as your content reference.
3. Create a scene named `Origin Map`.
4. Add:
   - Plane (ground)
   - Directional Light (sun)
   - Skybox material
   - Physics gravity enabled (`-9.81` y)
5. Add scripts in `Assets/Scripts` to GameObjects according to each script header.

## Scope
These scripts provide a functional starter architecture and placeholder implementations for all requested start task categories. They are designed to be expanded into full gameplay.
