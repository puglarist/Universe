# Contributing to Universe

## Workflow
1. Create/checkout a patch branch using naming convention `patch-XYZ-topic`.
2. Keep each pull request scoped to a single patch objective.
3. Update corresponding roadmap and task-tracking docs with progress.

## Commit Convention
Use conventional-style prefixes:
- `feat:` new capability
- `chore:` non-functional setup work
- `docs:` documentation updates
- `fix:` bug fix
- `refactor:` structural code change without behavior change

## Pull Request Checklist
- [ ] Patch objective is clearly stated.
- [ ] Related roadmap file updated in `docs/roadmap/`.
- [ ] Task board status synchronized.
- [ ] Relevant setup/test commands documented.
- [ ] No secrets committed.

## Folder Ownership (initial)
- `assets/` – Art and procedural output team.
- `ai/` – AI integration and prompt engineering team.
- `unity/` – Engine and gameplay systems team.
- `scripts/` – Tooling/DevOps automation team.
- `docs/` – PM/architecture documentation team.
