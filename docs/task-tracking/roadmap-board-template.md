# Roadmap Board Template (200+ Tasks)

## Suggested Columns
1. Backlog
2. Ready
3. In Progress
4. Blocked
5. Review
6. Done

## Required Fields
- Task ID (`UNI-0001`)
- Patch (`patch-000`, `patch-001`, ...)
- Workstream (Engine, AI, Assets, Build, Docs, Physics, Networking)
- Owner
- Priority (P0/P1/P2)
- Target Milestone
- Dependencies
- Definition of Done

## Task Naming Convention
`UNI-<number>: <short action-oriented title>`

Examples:
- `UNI-0001: Initialize Unity project with URP`
- `UNI-0002: Add GPT sandbox prompt->response flow`
- `UNI-0003: Validate first WebGL smoke build`

## Initial Workstream Buckets
- Foundation / Patch 0
- Core Engine / Patch 1
- AI Systems / Patch 2
- Physics & Simulation / Patch 3
- Content Pipeline / Patch 4
- Platform Build & QA / Patch 5+

## Governance Rhythm
- Daily standup: blocked tasks + dependency updates.
- Weekly planning: pull from Backlog to Ready.
- Patch closeout: verify all DoD criteria and move residuals forward.
