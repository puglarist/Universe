# PATCH-76 Release Notes

## Highlights
- Added portable computer device classes: Laptop, Rugged Laptop, Tablet, and Mini-PC Case.
- Added interaction loop for pickup, drop/place, inventory storage, vehicle cargo transfer, and mount-point placement.
- Added VOS shell with boot flow, desktop launcher, simulated file system directories, and status bar metadata.
- Added core app registry (Builder Console, World Notes, Blueprint Editor, Patchline Viewer, Asset Importer, Settings).
- Added admin/builder menu and backend hooks for creating devices, apps, and OS modules with permission gating.
- Added audit logging for all builder/admin operations, explicitly marked simulation-only.

## Safety
This patch is for in-simulation world-building only and does not implement real networking, exploitation, credential theft, or intrusion behaviors.
