# Universe

Starter scaffold for the **UNIVERSE PROJECT** prototype.

## Structure
- `engine/` Unity scaffold and C# starter scripts.
- `world/`, `characters/`, `combat/`, `ai/`, `network/`, `video/`, `codex/` module roots.

## Start here
1. Read `engine/unity/README.md`.
2. Open Unity LTS and create the `Origin Map` scene.
3. Attach scripts from `engine/unity/Assets/Scripts`.
4. Track implementation progress in `codex/MASTER_START_TASKS.md`.
