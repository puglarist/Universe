# Universe

## Inner Bridge Protocol (Terminal + Imagination Rehearsal)

This repo now includes a small CLI tool (`inner_bridge.py`) that helps you train a repeatable bridge between:

- Dream world / lucid imagination
- Meditative focus states
- Symbolic "GUI/terminal-like" mental gestures

It does this by combining:

1. Breath pacing
2. Intention repetition
3. Symbol sequence encoding
4. Gesture/action mapping rehearsal

> This is for mental rehearsal and focus training. It does not claim supernatural guarantees.

## Quick start

```bash
python3 inner_bridge.py
```

On first run, it creates `bridge_plan.json` with a default protocol.

## Customize your protocol

```bash
python3 inner_bridge.py --edit
```

You can adjust:

- Intention statement
- Number of repetitions
- Visual symbols (your inner "interface" objects)
- Gesture-to-action key bindings

## Useful options

```bash
python3 inner_bridge.py --plan my_plan.json --speed 3
```

- `--plan`: use a different JSON plan file.
- `--speed`: faster/slower pacing for countdowns and prompts.

## Example use pattern

1. Run a short session in terminal.
2. Close your eyes after completion.
3. Replay the same symbol and gesture sequence internally.
4. Repeat daily so the sequence becomes automatic and vivid.
